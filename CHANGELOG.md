# Changelog

## 0.1.0 — 2026-10-11

Initial public release.

- A reusable Codex custom Agent and a discoverable launcher skill.
- Typed local workflows for atomistic structure construction, molecular force fields, interactive 3D views and native VESTA export.
- Explicit artifact handoffs, graph-preserving molecular coordinate mapping, provenance hashes, dependency blocking and terminal-run integrity verification.
- Extensible capability descriptors with instruction-only routes or explicitly trusted Python adapters.
- Portable installation, a runnable public DMF workflow and an executable metadata-summary extension example.
- 91 passing tests and bounded local integration evidence. Scientific acceptance remains separate from technical completion.
