# Original coordinate fixture

`illustrative-water.xyz` contains three prescribed frames of one rigid water
molecule. The starting O/H coordinates are explicit construction choices:
O (0,0,0), H (0.9572,0,0), H (-0.239987,0.927297,0) in angstrom.
Frame i translates every atom by (0.1i,0,0) angstrom. There is no force field,
electronic calculation, integration timestep, optimization or experimental
claim. The fixture exercises source-file handoff, selected frames and an
independent offline viewer. Atom order is O,H,H in every frame.
